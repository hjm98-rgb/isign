Features

把签名这件事，做到极简

iSign 将证书管理、应用签名、分发安装整合为一个网页应用，摆脱对 Mac + Xcode 的依赖。

证书导入与管理

一键上传 .p12 证书与 .mobileprovision 描述文件，自动解析有效期、团队与 Bundle ID，多证书集中管理。

应用管理列表

已签名应用一目了然：图标、版本、Bundle ID、安装状态。刷新、删除、重新签名一键完成。

云端签名打包

借助 GitHub Actions 在云端完成 IPA 重签名，无需本地安装任何签名工具，随时随地打包。

点击即装

生成 OTA 安装链接，iPhone Safari 打开即可安装到桌面，无需数据线、无需电脑。

设置导入扩展

在设置中导入书籍、文件与其他资源，作为应用分发之外的资源管理入口，随时调用。

证书与安全提示

内置证书有效期提醒、描述文件匹配校验与安全使用指引，帮助你合规使用自有证书。
